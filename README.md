# Souqflow

Event-driven marketplace for Tunisian sellers: orders, inventory, payments and notifications run as separate Symfony Messenger consumers over RabbitMQ, with a live order-journey page.

- Brand color: `#E8890C`
- `backend/`  Symfony + API Platform
- `frontend/` React + Vite + TypeScript web app
- `docker-compose.yml` Postgres, Redis, Mailpit for local development

See `AGENTS.md` for the full project guide.
